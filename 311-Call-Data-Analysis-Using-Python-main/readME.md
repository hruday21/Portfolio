# 311 Call Data Analysis

## Project Overview
This project focuses on analyzing 311 service requests from multiple cities. The primary goals were to design and implement a normalized database to manage service requests effectively, reduce data redundancy, and improve operational efficiency. 

## Key Features
- **Normalized Database Design**: Collaborated with a team to create a database structure that minimizes redundancy and allows for efficient data management of 311 service requests.
- **Data Automation**: Developed Python scripts for automating the extraction, transformation, and loading (ETL) of data into a centralized database.
- **Predictive Analysis**: Applied the Naive Bayes algorithm to analyze historical data and predict average resolution times for service requests.

## Technologies Used
- **Database**: [MySQL]
- **Programming Language**: Python
- **Libraries**: Pandas, NumPy, scikit-learn
- **Tools**: [Jupyter Notebook]
