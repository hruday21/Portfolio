# Profit Analysis of a Paper Company

## Project Overview
This project involves conducting a profit analysis for a paper company. The main objectives were to analyze revenue streams, cost breakdowns, and profitability trends to support strategic decision-making.

## Key Features
- **Comprehensive Financial Analysis**: Developed a dashboard to visualize key financial metrics, enabling a better understanding of revenue and costs.
- **Profitability Trends**: Identified trends in profitability over time, helping the company to recognize key profit drivers and areas for improvement.
- **Strategic Insights**: Provided insights to support strategic planning and maximize profits through data-driven decisions.
